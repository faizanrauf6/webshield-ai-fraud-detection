## Is it fully developed?

**The controlled FYP implementation and deliverable package are ready for application testing and demonstration. General website-fraud accuracy and production suitability remain unestablished.**

The known example.com regression was fixed without an allowlist. The installed phishing model remains the validated lexical-v2 bundle. The richer character candidate improved recall on a reused historical holdout, then produced 12/100 false positives in the new reference pilot. It was not promoted. The high legitimate-HTTP error rate and archived cryptocurrency false positives are documented rather than hidden by aggregate scores.

The previously missing full feature comparison has now been executed prospectively with actual collection/provider times, frozen independently sourced label lists and all failed observations retained. On the shared 40-site group holdout, every selected stage made the same predictions: 18/18 phishing detections and 1/22 reference false positives. Within-session chronological sensitivity also failed to establish a hybrid advantage. These results do not support a claim that adding threat/content evidence always improves performance.

Only 64/200 domain and 41/200 content observations completed. Public-DNS problems were observed near collection completion; specific worker failure causes were not retained. Famous HTTPS homepage negatives versus arbitrary phishing paths also permit collection-source shortcuts. Historical timestamp-aligned threat snapshots remain absent from the old corpora; this new pilot is a separate contemporary experiment, not invented historical evidence. Independent representative current adjudication and sustained operational validation are still necessary before a broader deployment claim.

Accounts, wallet operations, on-chain tracing, screenshot classification and browser extensions remain outside the agreed controlled FYP scope. Independent academic/user acceptance is a human decision; the supplied checklist deliberately leaves signatures blank.
